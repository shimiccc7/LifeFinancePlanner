# LifeFinancePlanner

A mobile-first personal finance planning prototype focused on sustainable cash-flow decisions rather than extreme frugality.

## v0.1
- Monthly cash-flow dashboard
- Editable real-budget inputs
- Suggested allocation page with expandable rationale
- Annual travel sinking fund
- ESPP contribution ladder
- Monthly gamified missions / XP
- Browser-only localStorage persistence

## Privacy
This repository contains no real bank account numbers, credentials, or private financial records. User-entered values are stored only in the browser's localStorage in the current prototype.

## Product direction
- v0.2: 12-month cash-flow timeline and ESPP 8/10/12/15% scenarios
- v0.3: goals, emergency-fund runway, debt payoff, annual expense calendar
- v1.0: optional authentication and encrypted multi-device sync
- Later: configurable RSU/ESPP compensation module, not tied to a single employer

> Prototype only. Not tax, investment, or debt advice.
